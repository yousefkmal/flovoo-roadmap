## الترتيب

صفحة المُطلَق تعرض التسعة عشر بترتيب الملف بالضبط، من «الحملات متعددة الأيام» إلى فلتر جهات الاتصال في الموبايل.

أما اللوحة فترتّب بالأصوات أولًا، فتظهر الميزتان صاحبتا الصوت في المقدمة ثم البقية بترتيب الملف. هذا هو سلوك لوحة تصويت، وعمود الترتيب يفصل بين المتساويات فقط.

## ما يحتاج انتباهك

**الاسم العربي لـ AI Agents ناقص في رسالتك.** كتبتَ «الاسم الرسمي للمنتج هو AI Agents بالعربية [........]» وبقي الفراغ. لم أخترع اسمًا، واستعملتُ ما في ملف الاستيراد: **«وكلاء الذكاء الاصطناعي»**.

وبحثتُ عن الاسم الآخر كما طلبت. النتيجة:

| الاسم | أين يظهر |
| --- | --- |
| AI Employees / بناء موظفي ذكاء صناعي | مكانان فقط: الميزة ومسودتها في «الجديد». كلاهما حُدّث الآن، فلم يبقَ له أثر |
| AI Agents / الوكلاء الذكيون | تصنيف في مركز المساعدة، جاء من محتواك في Intercom |
| AI Agents / وكلاء الذكاء الاصطناعي | الميزة في خارطة الطريق، من ملف الاستيراد |

أي أن العربية غير موحّدة بين المنتجين: مركز المساعدة يقول «الوكلاء الذكيون» وخارطة الطريق تقول «وكلاء الذكاء الاصطناعي». أعطني الاسم الرسمي وأوحّد الاثنين بأمر واحد.

**`channel-access-for-members`** — الملف يعلّم نصّه العربي بـ REVIEW لأنه صيغ للملف ولم يأتِ من التقرير العربي الأصلي. استُورد كما هو، فراجِعه.

## الحقول التي لا يغطيها الملف والقيم المستعملة

| الحقل | القيمة |
| --- | --- |
| `source` | `internal` |
| `vote_count` | 0 للجديد، وبلا مساس بالموجود |
| `is_pinned` | `false` — لم يُثبَّت شيء |
| `sort_order` | رقم `order` من الملف |
| نص «الجديد» | الوصف محوّلًا إلى نسق الكتل |
| `kind` | feature ← جديد، improvement ← تحسين، mobile ← جديد |
| غلاف «الجديد» ووصفه البديل | فارغ |
| `published_at` للمسودات | فارغ |
